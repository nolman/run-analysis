# Run Analysis

This code can be used to compare multiple different raid runs in order to identify areas of improvement as well as provide a way to measure week over week changes.

## Running locally

This is an Ember CLI app. The project is pinned to Node 14.21.3 with asdf because its older dependency set includes `node-sass`.

```sh
asdf install
yarn install --frozen-lockfile
yarn start
```

The app runs at http://localhost:4333/.
